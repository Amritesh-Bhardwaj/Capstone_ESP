Features

Live value against the empty-room band from the calibration (median ± 2 MAD), with the Gate 1 scores that decided whether each one is trustworthy.

FeatureLiveEmpty-room band AUC vs occupiedAUC vs 2nd empty roomVerdict
Why two AUC columns. The first says a feature separates an empty room from an occupied one. The second says it separates an empty room from a different empty session — where the honest answer is 0.5. A feature scoring high in both is detecting the session, not the person. That is exactly what motion_score does (0.998 vs 0.986), and it is what the older presence path is built on. Rank features measure the shape of the subcarrier covariance, which is scale-invariant, so link changes leave them alone.
